# ADR-0001: Follow the engineering playbook

- Date: 2026-11-27
- Status: Accepted

## Context

This project started from the engineering playbook's starter at playbook commit `b04a04f` (b04a04f86d8ba9f339f50be2aba5e9eed4e210ce), the head of [engineering-playbook PR #2](https://github.com/tomchen86/engineering-playbook/pull/2) before that PR was reviewed or merged. If its review changes the starter, bring those changes into this repo. The playbook asks eight questions and gives a default answer to each.

## Decision

- Level: 1, a product maintained for the long term (chapter 0). It handles no money and no one else's data, so it has no level-2 areas.
- Changes that merge without a human looking: none
- Deviations from the playbook defaults: none

## Consequences

Later deviations get their own ADR.
